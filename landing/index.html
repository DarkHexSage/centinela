Lo que un agente puede hacer sin que te des cuenta

    
Los modelos inventan nombres de paquetes, leen tu .env para "entender la configuración" y pegan keys en el código. Centinela lo frena en el momento y le explica al agente qué hacer en su lugar.

    

      
📦 Paquetes alucinados
Si la AI inventa supabase-auth-pro y un atacante lo registra, instalarlo corre su código. Centinela verifica en npm y PyPI antes de instalar.

      
🎭 Typosquatting
lodahs, reqeusts, expresss. Detecta nombres casi iguales a paquetes populares y los que npm retiró por maliciosos.

      
🔑 Lectura de secrets
Bloquea cat .env, llaves SSH y credenciales de nube para que tus keys no terminen en el contexto del modelo.

      
📤 Exfiltración
Comandos que combinan secrets y red, como curl -d @.env o printenv | curl.

      
🧾 Keys hardcodeadas
Stripe live, OpenAI, Anthropic, AWS, GitHub, URLs de base de datos, el JWT service_role de Supabase y variables NEXT_PUBLIC_*SECRET.

      
💥 Comandos destructivos
rm -rf ~, git push --force a main, DROP TABLE, terraform destroy, curl | sh.

Claude Code
Plugin completo: hooks, MCP y skill de auditoría.
/plugin marketplace add securedev/centinela
/plugin install centinela@centinela

      
Cursor
Hooks de shell y lectura, más el MCP.
npm i -g centinela-ai
centinela init cursor

      
CI / cualquier MCP
Falla el pipeline si hay secrets o dependencias sospechosas.
npx -y centinela-ai scan .
